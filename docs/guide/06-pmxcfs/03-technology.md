# 6.3. 技术 <a href="#_technology" id="_technology"></a>

我们使用 [Corosync Cluster Engine](https://www.corosync.org) 进行集群通信，并使用 [SQlite](https://www.sqlite.org) 作为数据库文件。该文件系统使用 [FUSE](https://github.com/libfuse/libfuse) 在用户空间中实现。
