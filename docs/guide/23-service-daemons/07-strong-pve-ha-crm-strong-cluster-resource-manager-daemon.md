# 23.7. **pve-ha-crm** \- Cluster Resource Manager Daemon <a href="#_strong_pve_ha_crm_strong_cluster_resource_manager_daemon" id="_strong_pve_ha_crm_strong_cluster_resource_manager_daemon"></a>

<a id="cli_pve-ha-crm"></a>



**pve-ha-crm** `<COMMAND> [ARGS] [OPTIONS]`

<a id="cli_pve-ha-crm_help"></a>



**pve-ha-crm help** `[OPTIONS]`

获取指定命令的帮助。

**`--extra-args` `<array>`**

显示特定命令的帮助

**`--verbose` `<boolean>`**

详细输出格式。

<a id="cli_pve-ha-crm_start"></a>



**pve-ha-crm start** `[OPTIONS]`

Start the daemon.

**`--debug` `<boolean>`（*默认 \=* `0`）**

Debug mode \- stay in foreground

<a id="cli_pve-ha-crm_status"></a>



**pve-ha-crm status**

Get daemon status.

<a id="cli_pve-ha-crm_stop"></a>



**pve-ha-crm stop**

Stop the daemon.
