# `/nodes/{node}/qemu/{vmid}/firewall/ipset/{name}`

原始接口路径：`/nodes/{node}/qemu/{vmid}/firewall/ipset/{name}`。

方法、参数名、类型、默认值和枚举值与官方规范一致。

## DELETE `/nodes/{node}/qemu/{vmid}/firewall/ipset/{name}`

Delete IPSet

**方法标识：** `delete_ipset`

**权限**

```json
{
  "check": [
    "perm",
    "/vms/{vmid}",
    [
      "VM.Config.Network"
    ]
  ]
}
```

**允许 API 令牌**

```json
1
```

**受保护接口**

```json
1
```

### 请求参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `force` | boolean | 否 | — | Delete all members of the IPSet, if there are any. |
| `name` | string | 是 | — | IP set name. |
| `node` | string | 是 | — | The cluster node name. |
| `vmid` | integer | 是 | — | The (unique) ID of the VM. |

