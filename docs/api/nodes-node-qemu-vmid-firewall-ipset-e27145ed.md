# `/nodes/{node}/qemu/{vmid}/firewall/ipset`

原始接口路径：`/nodes/{node}/qemu/{vmid}/firewall/ipset`。

方法、参数名、类型、默认值和枚举值与官方规范一致。

## GET `/nodes/{node}/qemu/{vmid}/firewall/ipset`

列出 IPSet

**方法标识：** `ipset_index`

**权限**

```json
{
  "check": [
    "perm",
    "/vms/{vmid}",
    [
      "VM.Audit"
    ]
  ]
}
```

**允许 API 令牌**

```json
1
```

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `node` | string | 是 | — | 集群节点名称。 |
| `vmid` | integer | 是 | — | 虚拟机的（唯一）ID。 |

## POST `/nodes/{node}/qemu/{vmid}/firewall/ipset`

创建新 IPSet

**方法标识：** `create_ipset`

**权限**

```json
{
  "check": [
    "perm",
    "/vms/{vmid}",
    [
      "VM.Config.Network"
    ]
  ]
}
```

**允许 API 令牌**

```json
1
```

**受保护接口**

```json
1
```

### 请求参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `comment` | string | 否 | — |  |
| `digest` | string | 否 | — | 如果当前配置文件具有不同的摘要，则阻止更改。这可用于防止并发修改。 |
| `name` | string | 是 | — | IP 集合名称。 |
| `node` | string | 是 | — | 集群节点名称。 |
| `rename` | string | 否 | — | 重命名现有 IPSet。可以将 'rename' 设为与 'name' 相同的值，以更新现有 IPSet 的 'comment'。 |
| `vmid` | integer | 是 | — | 虚拟机的（唯一）ID。 |
