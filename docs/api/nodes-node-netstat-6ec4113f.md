# `/nodes/{node}/netstat`

原始接口路径：`/nodes/{node}/netstat`。

方法、参数名、类型、默认值和枚举值与官方规范一致。

## GET `/nodes/{node}/netstat`

读取 tap/虚拟机网络设备接口计数器

**方法标识：** `netstat`

**权限**

```json
{
  "check": [
    "perm",
    "/nodes/{node}",
    [
      "Sys.Audit"
    ]
  ]
}
```

**允许 API 令牌**

```json
1
```

**代理目标**

```json
"node"
```

### 请求参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `node` | string | 是 | — | 集群节点名称。 |
