# `/nodes/{node}/qemu/{vmid}/firewall/aliases/{name}`

原始接口路径：`/nodes/{node}/qemu/{vmid}/firewall/aliases/{name}`。

方法、参数名、类型、默认值和枚举值与官方规范一致。

## DELETE `/nodes/{node}/qemu/{vmid}/firewall/aliases/{name}`

移除 IP 或网络别名。

**方法标识：** `remove_alias`

**权限**

```json
{
  "check": [
    "perm",
    "/vms/{vmid}",
    [
      "VM.Config.Network"
    ]
  ]
}
```

**允许 API 令牌**

```json
1
```

**受保护接口**

```json
1
```

### 请求参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `digest` | string | 否 | — | 如果当前配置文件具有不同的摘要，则阻止更改。这可用于防止并发修改。 |
| `name` | string | 是 | — | 别名名称。 |
| `node` | string | 是 | — | 集群节点名称。 |
| `vmid` | integer | 是 | — | 虚拟机的（唯一）ID。 |
