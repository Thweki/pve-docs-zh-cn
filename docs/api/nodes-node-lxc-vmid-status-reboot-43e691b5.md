# `/nodes/{node}/lxc/{vmid}/status/reboot`

原始接口路径：`/nodes/{node}/lxc/{vmid}/status/reboot`。

方法、参数名、类型、默认值和枚举值与官方规范一致。

## POST `/nodes/{node}/lxc/{vmid}/status/reboot`

通过先关闭再启动来重启容器。应用待处理的更改。

**方法标识：** `vm_reboot`

**权限**

```json
{
  "check": [
    "perm",
    "/vms/{vmid}",
    [
      "VM.PowerMgmt"
    ]
  ]
}
```

**允许 API 令牌**

```json
1
```

**受保护接口**

```json
1
```

**代理目标**

```json
"node"
```

### 请求参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `node` | string | 是 | — | 集群节点名称。 |
| `timeout` | integer | 否 | — | 最多等待 timeout 秒以完成关闭。 |
| `vmid` | integer | 是 | — | 虚拟机的（唯一）ID。 |
