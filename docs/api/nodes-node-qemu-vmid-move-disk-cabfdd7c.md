## POST `/nodes/{node}/qemu/{vmid}/move_disk`

将卷移动到其他存储或其他虚拟机。

**方法标识：** `move_vm_disk`

**权限**

```json
{
  "check": [
    "perm",
    "/vms/{vmid}",
    [
      "VM.Config.Disk"
    ]
  ],
  "description": "需要对 /vms/{vmid} 具有 'VM.Config.Disk' 权限，以及对存储具有 'Datastore.AllocateSpace' 权限。要将磁盘移至另一个虚拟机，还需要对目标虚拟机具有相应权限。"
}
```

**允许 API 令牌**

```json
1
```

**受保护接口**

```json
1
```

**代理目标**

```json
"node"
```
