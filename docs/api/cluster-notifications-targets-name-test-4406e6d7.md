# `/cluster/notifications/targets/{name}/test`

原始接口路径：`/cluster/notifications/targets/{name}/test`。

方法、参数名、类型、默认值和枚举值与官方规范一致。

## POST `/cluster/notifications/targets/{name}/test`

Send a test notification to a provided target.

**方法标识：** `test_target`

**权限**

```json
{
  "check": [
    "or",
    [
      "perm",
      "/mapping/notifications",
      [
        "Mapping.Modify"
      ]
    ],
    [
      "perm",
      "/mapping/notifications",
      [
        "Mapping.Audit"
      ]
    ],
    [
      "perm",
      "/mapping/notifications",
      [
        "Mapping.Use"
      ]
    ]
  ]
}
```

**允许 API 令牌**

```json
1
```

**受保护接口**

```json
1
```

### 请求参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `name` | string | 是 | — | Name of the target. |
