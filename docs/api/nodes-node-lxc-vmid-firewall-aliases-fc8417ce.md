# `/nodes/{node}/lxc/{vmid}/firewall/aliases`

原始接口路径：`/nodes/{node}/lxc/{vmid}/firewall/aliases`。

方法、参数名、类型、默认值和枚举值与官方规范一致。

## GET `/nodes/{node}/lxc/{vmid}/firewall/aliases`

列出别名

**方法标识：** `get_aliases`

**权限**

```json
{
  "check": [
    "perm",
    "/vms/{vmid}",
    [
      "VM.Audit"
    ]
  ]
}
```

**允许 API 令牌**

```json
1
```

| --- | --- | --- | --- | --- |
| `node` | string | 是 | — | 集群节点名称。 |
| `vmid` | integer | 是 | — | 虚拟机的（唯一）ID。 |

## POST `/nodes/{node}/lxc/{vmid}/firewall/aliases`

创建 IP 或网络别名。

**方法标识：** `create_alias`

**权限**

```json
{
  "check": [
    "perm",
    "/vms/{vmid}",
    [
      "VM.Config.Network"
    ]
  ]
}
```

**允许 API 令牌**

```json
1
```

**受保护接口**

```json
1
```

### 请求参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `cidr` | string | 是 | — | CIDR 格式的网络/IP 规范。 |
| `comment` | string | 否 | — |  |
| `name` | string | 是 | — | 别名名称。 |
| `node` | string | 是 | — | 集群节点名称。 |
| `vmid` | integer | 是 | — | 虚拟机的（唯一）ID。 |
