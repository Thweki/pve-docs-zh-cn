# `/nodes/{node}/replication`

原始接口路径：`/nodes/{node}/replication`。

方法、参数名、类型、默认值和枚举值与官方规范一致。

## GET `/nodes/{node}/replication`

列出此节点上所有复制任务的状态。

**方法标识：** `status`

**权限**

```json
{
  "description": "需要在 /vms/<vmid> 上拥有 VM.Audit 权限。",
  "user": "all"
}
```

**允许 API 令牌**

```json
1
```

**受保护接口**

```json
1
```

**代理目标**

```json
"node"
```

### 请求参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `guest` | integer | 否 | — | 仅列出此客户机的复制作业。 |
| `node` | string | 是 | — | 集群节点名称。 |
